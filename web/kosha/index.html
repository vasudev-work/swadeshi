Kosha is a reading room for Indian open source. Every card points at a public GitHub Release, so the build comes from the developer, not from here.

Nothing is uploaded, rated or ranked by us. Stars, licence and size are read from GitHub and shown as they are.

Look and feel follows the Nijatva signature system: four surfaces, three accents, one tile geometry. Data rebuilt daily from swadeshi-gh-store.
